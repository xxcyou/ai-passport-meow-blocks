# 猫猫方块

FoloToy AI Passport(ESP32-C3,240x320 屏,三键 ADC)上的离线找猫解谜应用。
棋盘上藏着若干只猫,玩家靠推理把不可能的格子打叉排除,再确认自己推出的猫。
每关唯一解,所以答案是"推"出来的,不是猜出来的。

## 规则

1. 任意一行、任意一列最多 1 只猫。
2. 一块四连通同色区域最多 1 只猫。色块数量等于目标猫数,因此每块恰好 1 只。
3. 两只猫不能相邻,包括四个斜对角。
4. 每关只有一组合法摆法(生成时逐关验证)。

目标猫数由关卡表给定。全部隐藏猫都被确认、且没有把错格确认成猫,即通关。

## 操作

设备只有三个按键:`上`、`下`、`确定`(短按、双击、长按)。

| 输入 | 效果 |
| --- | --- |
| `下` | 光标下移一行;已在最后一行则从第一行回来 |
| `上` | 光标右移一列;已在最右列则从最左列回来 |
| 长按 `下` / `上` | 300ms 后进入快速移动,每 90ms 走一格 |
| 短按 `确定` | 在光标格打叉(排除);再按取消 |
| 双击 `上` / `下` | 光标后退一格(左 / 上),这样两个键就能覆盖四个方向 |
| 双击 `确定` | 确认这一格是猫;再双击取消 |
| 待机时按任意键 | 唤醒屏幕;这一下不做其它动作 |
| 长按 `确定` | 打开菜单。菜单分两页:主页(继续、重开、提示、设置、玩法、关卡列表)和设置页(自动排除、音量、静音、待机、重置进度、返回)。打开菜单/音量页/教学时,计时和限时倒计时全部暂停。 |
| 音量页 `上` / `下` | 音量 +10 / -10(长按 `确定` 回菜单) |

如果某块同色区域还没找到猫,却被你排掉了最后一种可能,屏幕会提示"这个颜色还没有找到猫"——
这块区域就再也放不下猫了,这一关也就走不通,提示是让你早点发现。

叉只是笔记。确认才是"下注":确认的格子不是猫,那一格会留下**永久红叉**(不能取消、
也不能再确认),同时抖一下、播一声短促的错误音,并扣一颗爱心;两颗都扣完这局重来。
已经被规则排除的格子(同行、同列、同色块、或紧挨着已确认的猫)根本不允许确认,
所以"找到数"永远不可能超过目标数。

### 自动排除辅助

确认一只猫时,顺手把这只猫"规则上已经不可能"的格子全部打叉:同行、同列、四周八格、
以及**整块同色区域的所有其余格子**(手动确认和"提示"补猫走的是同一条路径)。
自动叉用偏深的颜色,14 种色块底色上都看得清。自动叉画得比手打的叉浅;实现上每格记的是"有多少只已确认的猫排除了
我"的计数 —— 撤销一只猫只收回它贡献的那部分叉,手打的叉不会被误删。

## 顶栏、计时与星级

游戏页顶栏:第一行是关卡号、两颗爱心、右上角电量百分比;第二行是棋盘尺寸、找到数/目标数和计时
(限时关显示剩余时间,最后 30 秒变红)。

设置页里还能设待机:无操作 1 / 3 / 5 / 10 分钟后自动关屏,按任意键唤醒(唤醒那一下不会移动光标),
待机期间本关计时也暂停。默认关闭。

150 关起限时:150-199 关 400 秒,200-249 关 300 秒,250-299 关 240 秒,之后 200 秒。
时间到和爱心耗尽一样判负。

通关会播一段演出:所有猫头放大到 1.5 倍、旋转一下,然后底部进度条一只一只被猫头填满,
最后弹出结算面板。星级共三星、按半星计:每丢一颗爱心扣半星;用时超过基准(4 秒 +
每只猫 5 秒)1.5 倍扣半星、2 倍扣一整星。面板上有"下一关"和"重试"。

## 界面

- **关卡列表** —— 只列已通关的关和当前这一关,后面的关完全不显示。已通关绿色,
  当前关蓝灰,选中项有琥珀色边框。已通关的格子在关卡号下面还有一条**三星条**,
  显示这一关的最好成绩(半亮的段就是半星),方便回头刷分。
- **游戏页** —— 关卡号、爱心、计时、棋盘尺寸、找到数/目标、自绘棋盘、两行操作提示。
- **新手教学** —— 前 5 关进入时先弹一张带图的规则卡:三个 4x4 小棋盘分别演示
  行/列规则、同色区域规则、八邻域规则,再加一行按键说明。弹窗期间暂停计时,
  第 6 关起不再出现。
- **菜单 / 玩法 / 通关 / 失败** —— 叠加在游戏页上的浮层。

方块画成轻微凸起的小砖:棋盘底下铺一层深色缝,每块砖内缩、圆角,顶边提亮、底边压暗。
这只是明暗处理,不是 3D。14 种色块底色用"HSV 空间最远点采样"挑出来,两两最小色差足够大,
16px 的格子上也能分清;同时都保持较高亮度,深色猫头和叉压上去仍然清楚。

动效都走廉价路线:确认的猫从 60% 弹到 100%,自动叉从猫头一圈圈向外扩散,猜错那格抖一下,
通关时所有猫放大到 1.5 倍、旋转,再让进度条一只一只被猫头填满。棋盘和关卡格子各由一个 `LV_EVENT_DRAW_MAIN` 自绘回调画完,
猫、叉、爱心、星星都是 8x8 像素图,整个界面不需要任何图片素材。

## 关卡阶梯

| 关卡 | 棋盘 | 猫数 | 意图 |
| --- | --- | --- | --- |
| 1-3 | 4x4 | 3 | 猫最少、色块最大 |
| 4-6 | 4x4 | 4 | 行满列满 |
| 7-8 | 5x5 | 4 | 空一行一列 |
| 9-12 | 5x5 | 5 | 5x5 满编 |
| 13-17 | 6x6 | 6 | 6x6 满编 |
| 18-20 | 7x7 | 7 | 7x7 满编 |
| 21-80 | 8x8 到 14x14 | 8-14 | 难度来自色块布局 |

21 关起每十关为一个难度阶梯,同一阶梯在两种相邻尺寸之间交替(8/9、9/10……
13/14);上限固定 14x14,后期难在色块形状把候选位置压窄,而不是棋盘变大。
难度用"纯逻辑传播"度量(推导轮数、卡住后首个分支的候选数),同一阶梯内非递减。

**为什么最小棋盘是 4x4:** 在三条规则加唯一解要求下,2x2 与 3x3 根本不存在
合法关卡。2x2 里一只猫可以落在四个格子中的任意一个,任何划分都无法让答案唯一;
3x3 里任意两格都相邻,k=3 无合法摆法,k=1 必然多解,而对"所有答案集合 ×
所有两色块划分"的穷举也找不到任何唯一的 k=2 关卡。4x4 才是存在唯一解的最小棋盘。

### 无尽关卡

没有最后一关。1-80 关来自 Python 生成器,81-200 关来自 `tools/gen_catcube_extra.c`
里的 C 生成器(同一套算法、确定性种子、失败换种子重试,每关都验证过唯一解)。
200 关之后,关卡由表里的某一关按关号做固定的对称变换(转置/镜像/旋转)再整体换色得到;
对称变换是双射,唯一解、每块一只猫、八邻域约束全部保留,而且同一关号永远得到同一张图
—— 重置游戏后再玩第 100 关还是这一关。

1-80 关的完整清单(中文,固定格式)见
[`catcube-levels.txt`](catcube-levels.txt)。

## 生成算法

`tools/gen_catcube_levels.py` 用逆向生成法产出关卡表:

1. 先放一组已经满足规则 1、3 的猫坐标;
2. 以这些猫为种子生长出 k 个四连通色块,每块恰好含一只猫并覆盖全盘;
3. 在成品棋盘上枚举全部解,只有解数恰好为 1 才保留。否则"迁移杀解":
   取一个多余解,把它里面某个非答案格移进"已经含有该解另一格"的相邻色块,
   每步都重新校验色块连通与每块一只猫,然后重新枚举。

`python3 tools/gen_catcube_levels.py --check` 会重新校验已入库的数据
(色块连通、每块一只猫、规则满足、唯一解、C/JSON/TXT 一致、阶梯难度非递减)。

## 校验

```bash
./tools/validate.sh --static     # 仓库检查 + 主机测试
./tools/validate.sh --firmware   # ESP-IDF 构建 + 合并镜像校验
```

`tests/test_catcube_logic.c` 用 C 重新实现了一遍解的枚举,对 80 关逐关断言
解数恰好为 1 —— 与 Python 生成器完全独立;同时覆盖光标绕回、叉/猫切换、
冲突掩码与通关判定。
