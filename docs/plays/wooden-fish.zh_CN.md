# 功德木鱼:一个随身计数器玩法

功德木鱼把 AI Passport 变成随身的功德计数器:按一下确定键就敲一次木鱼,响一声、
数字 +1,断电也不丢。连击有提示,音色不用连电脑就能换。

这是基于基线 BSP 的二次开发应用,不使用基线的测试菜单、测试页面和 `ui_pixel`
视觉外壳,详见[界面重做要求](../development/ai-guide.zh_CN.md#mandatory-ui-redesign-for-derivative-applications)。

## 按键

| 页面 | 按键 | 短按 | 长按(500ms) |
| --- | --- | --- | --- |
| 敲击页 | 确定 | 敲一次(功德 +1) | 打开归零确认 |
| 敲击页 | 上 | 切换音色:木鱼 / 铜铃 / 木鼓 | 打开功德簿 |
| 敲击页 | 下 | 静音开关 | - |
| 归零确认 | 确定 | 确认归零 | 确认归零 |
| 归零确认 | 上 / 下 | 取消 | 取消 |
| 功德簿 | 确定 | - | 返回敲击页 |

长按后 400ms 内的单击会被忽略:按键组件对同一次物理按压可能同时产生长按和单击,
不挡掉的话"长按确定打开确认框"会立刻被当成"确认归零"。

## 页面

- **敲击页**:标题、右上角电量、三个圆角形状拼出的木鱼、48px 数字功德数、单位、
  连击角标、两行提示。敲击时木鱼放大回弹、光圈扩散淡出、`+1` 上浮、数字跳动。
- **功德簿**:本次功德、累计功德、最高连击、当前音色、静音状态。
- **归零确认**:压暗的浮层 + 琥珀色面板,只有确定键会清零。

## 行为与数据

| 项目 | 规则 |
| --- | --- |
| 连击 | 1500ms 内连敲算连击,上限 999 |
| 计数上限 | 99,999,999,到顶不再增长,不回绕 |
| 持久化 | 累计功德、最高连击、音色、静音存入 NVS 命名空间 `wf_merit` |
| 落盘策略 | 敲击只标脏,由输入任务最多每 5s 落盘一次;归零和改设置立即落盘 |
| 本次功德 | 刻意不持久化,每次开机从 0 开始 |

本板没有实时时钟,所以功德簿用"本次 / 累计"而不是"今日"。要加"今日"必须先有时
间源,并单独决定它的可信度。

## 声音

敲击音在运行时合成(`main/app/knock_synth.c`):两个指数衰减的正弦模态 + 一段短噪声
瞬态,16kHz / 16bit / 单声道渲染。每种音色是一组参数,连击每级升 6Hz、封顶 +36Hz。
不嵌入音频素材,因此不涉及音频版权,换音色也不占 Flash。

播放跑在独立任务里,是 I2S 的唯一写入者;按键回调只入队,队列满时丢弃本次请求而不是
阻塞输入。

## 中文与字体

界面文案集中在 `main/app/app_strings.h`。`tools/gen_app_fonts.py` 从该头文件抽取非
ASCII 字符,用 `lv_font_conv` 1.5.2 从 Droid Sans Fallback 生成
`assets/fonts/app_cjk_16.c` 与 `app_cjk_24.c`。ASCII 与数字走 LVGL 内置 Montserrat
的应用侧 fallback 链,因为源字库没有拉丁字形。

两道检查保证覆盖不是"看起来对":

- `tests/test_app_font_coverage.py` 解码生成字库的 cmap,任一界面码点缺失即失败,
  并带一个必然缺失的反例,避免测试空转。
- 应用启动时调用 `app_fonts_check_coverage()`,把缺失码点以 `U+XXXX` 打到串口日志。

## 构建与刷写

```bash
source <esp-idf-v5.5.3>/export.sh
./tools/validate.sh            # 静态检查 + 主机测试 + 合并固件
```

校验脚本产出 `build/FoloToy-AI-Passport-full.bin`,即从 `0x0` 刷写的合并镜像。合并刷写
可能重置已存数据,见[刷写与数据策略](../development/engineering/firmware-layout.zh_CN.md#flashing-and-stored-data)。

## 已知限制

- 没有做深度睡眠:打开期间设备保持唤醒,空闲功耗未优化,也没有按键唤醒处理。
- 设置只有音色和静音,没有亮度或音量菜单。
- 敲击动画按 16ms 帧驱动,顺滑程度属于真机检查项,主机侧测试证明不了。
